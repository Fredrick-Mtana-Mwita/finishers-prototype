# Finishers Point Africa – clickable prototype

Interactive prototype of the Finishers Point Africa online store (Mwanza, Tanzania) and its staff dashboard.

- Responsive: works on desktop, tablet and phone.
- Storefront: categories, search, product pages, cart, checkout, order confirmation, contractor materials list, help pages.
- Staff dashboard: footer → **Staff login** (any details work in this prototype).

All data is sample data stored only in the visitor's browser. Nothing is sent anywhere.
